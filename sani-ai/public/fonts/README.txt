Handwriting fonts go here. Run `npm run fonts` to download open-licence (SIL OFL) fonts from Google Fonts.

File name prefix tells the renderer which script a font supports:
  latin-*.ttf       English / Hinglish
  devanagari-*.ttf  Hindi (must also contain Latin digits)
  gurmukhi-*.ttf    Punjabi

You can add your own .ttf/.otf files with those prefixes. Each page picks one font per generation (seeded),
so more fonts = more variety. Check each font's licence before commercial use.
